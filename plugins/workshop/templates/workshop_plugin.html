What "Off" turns off

  • The workshop pages: /workshop, each part, the toolbox and the runtime pop-out.
  • The landing redirect. / serves the index Page again and login goes to /challenges.
  • The runtime dist, the saved work-in-progress API and the path graph.
  • The code door on the login page, and the registration codes' page.
  • Jump: the button on the login page, /jump/enter and the queue that posts solves back.
  • The supervisor tier: /supervisor/join and the room's pages. Supervisor accounts stay, as ordinary hidden users.
  • The workshop admin pages: mode, answers, stats, submissions, feedback, sync and Jump.

What "CTF with codes" keeps from that list

  • The code door. The login page opens on it, and / sends a visitor who is not signed in there. Staff sign in at /login?staff=1.
  • Registration codes, in the admin bar: each code is a cohort, with its own scoreboard and participant list.
  • Nothing else. There is no supervisor page, no certificate and no Jump in this state, and the challenges are the ones you create in the admin panel. Whether the board is open is CTFd's own start time and challenge visibility; a participant who comes in before that is told to come back.
  • CTFd's own registration page is not changed by this switch. Set "Registration visibility" to private in CTFd's settings if the codes must be the only way in: an account made there is behind no code, and shares one scoreboard with every other account of that kind.

What no state touches

  • The Epitech theme. The shell and the stylesheets stay. Turning the workshop off is not a request for CTFd's own navbar back.
  • Your content. Challenges, solves, the authored Pages the sync created ("Parcours", the subject index) and every supervisor account are untouched. Delete them from the admin panel if you want them gone; a switch that deleted content would not be a switch.
  • Quiz challenges. They keep working on the board: taking the challenge type away would break every quiz already imported.
  • What is not kept. No address is stored and no submitted text is written to the logs, in any state.
