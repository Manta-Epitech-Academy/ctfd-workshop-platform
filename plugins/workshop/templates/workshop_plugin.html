What disabling turns off

  • The workshop pages: /workshop, each part, the toolbox and the runtime pop-out.
  • The landing redirect. / serves the index Page again and login goes to /challenges.
  • The runtime dist, the saved work-in-progress API and the path graph.
  • Jump: the button on the login page, /jump/enter and the queue that posts solves back.
  • The supervisor tier: /supervisor/join and the room's pages. Supervisor accounts stay, as ordinary hidden users.
  • The workshop admin pages: mode, answers, stats, submissions, feedback, sync and Jump.

What it deliberately leaves alone

  • The Epitech theme. The shell and the stylesheets stay. Turning the workshop off is not a request for CTFd's own navbar back.
  • Your content. Challenges, solves, the authored Pages the sync created ("Parcours", the subject index) and every supervisor account are untouched. Delete them from the admin panel if you want them gone; a switch that deleted content would not be a switch.
  • Quiz challenges. They keep working on the board: taking the challenge type away would break every quiz already imported.
