{# The runtime, on a page of its own (PLAN.md §14.2 "keep a separate tab as an optional pop out, not the default"; §30 for the decision). Why a page and not `window.open(runtime.src)`: the runtime never talks to CTFd (PLAN.md §14.3 rule 1), a host does, and the host is what carries the protocol, the participant's work in progress (§16) and the advisory rules (rule 0). Opening the runtime's own dist in a tab would be a runtime with no host — no `init`, no step, no snapshot, no restore-before-boot — so the tab gets the same host the pane has, and `assets/runtime.js` runs here too. Deliberately NOT extending base.html. The shell's job is navigation and this page has one control and one frame; inheriting a header, a hero, a footer and a main padding only to hide them again is more markup, not less. The price is the three things base.html would have given for free, and each is here: `window.init` (trimmed to what the host actually reads), the stylesheets through the same `Plugins.styles` every page uses, and the theme. #} {{ runtime.title }} — {{ doc.title }} {{ Assets.css("assets/scss/main.scss") }} {{ Plugins.styles }} {# The theme, inline, instead of core's `color_mode_switcher.js`.
